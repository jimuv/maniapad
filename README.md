# maniapad


### Inspiration

I wanted to create a macropad that would allow me to play 4 key Vertical Scrolling Rhythm Games. I created a macropad using 4 switches.

### Challenges

Although I had some beginner experiences in SolidWorks, I have not fully developed the skills needed for 3D CAD, which in addition to this, was having to migrate to Fusion 360, which is similar, though it threw me off a bit. I had to go step by step as well as trying to find the tools needed to start modeling. A lot of these tools are scattered to me as I do not have the muscle memory or actual memory of where tools are usually placed, such as sketching or changing my views.


### Specifications
